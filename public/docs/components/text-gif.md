# GIF 文字 (Text GIF)

> 模拟 GIF 循环跳动的文字效果。

- 分类:文字与排版
- 本站页面:https://cult-ui.ndjp.net/docs/components/text-gif
- 官方文档:https://www.cult-ui.com/docs/components/text-gif
- 源码位置:`src/components/ui/text-gif.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/text-gif
~~~

## 用法

~~~tsx
import { TextGif } from "@/components/ui/text-gif"

export function Example() {
  return (
    <TextGif>内容</TextGif>
  )
}
~~~
