# 流光输入框 (Border Beam Input)

> Base UI 输入框与输入组上加流动光束,可选底边或整圈。

- 分类:表单与输入
- 本站页面:https://cult-ui.ndjp.net/docs/components/border-beam-input
- 官方文档:https://www.cult-ui.com/docs/components/border-beam-input
- 源码位置:`src/components/ui/border-beam-input.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/border-beam-input
~~~

## 用法

~~~tsx
import { BorderBeamInput, BorderBeamInputGroup, BorderBeamInputGroupAddon } from "@/components/ui/border-beam-input"

export function Example() {
  return (
    <BorderBeamInput>
      <BorderBeamInputGroup />
    </BorderBeamInput>
  )
}
~~~
