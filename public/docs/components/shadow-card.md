# 阴影卡片 (Shadow Card)

> L 形成型阴影的营销卡片,可选像素渐变网格与链接根节点。

- 分类:卡片
- 本站页面:https://cult-ui.ndjp.net/docs/components/shadow-card
- 官方文档:https://www.cult-ui.com/docs/components/shadow-card
- 源码位置:`src/components/ui/shadow-card.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/shadow-card
~~~

## 用法

~~~tsx
import { ShadowCard } from "@/components/ui/shadow-card"

export function Example() {
  return (
    <ShadowCard />
  )
}
~~~
