# 流体渲染插画 (Illustration Fluid Rendering)

> 把浏览器连接到电商与 CMS 平台的 SVG 插画。

- 分类:插画
- 本站页面:https://cult-ui.ndjp.net/docs/components/illustration-fluid-rendering
- 官方文档:https://www.cult-ui.com/docs/components/illustration-fluid-rendering
- 源码位置:`src/components/ui/illustration-fluid-rendering.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/illustration-fluid-rendering
~~~

## 用法

~~~tsx
import { FluidRendering, FluidRenderingBigCommerceIcon, FluidRenderingContentfulIcon } from "@/components/ui/illustration-fluid-rendering"

export function Example() {
  return (
    <FluidRendering>
      <FluidRenderingBigCommerceIcon />
    </FluidRendering>
  )
}
~~~

## 导出部件

- `FluidRendering`
- `FluidRenderingBigCommerceIcon`
- `FluidRenderingContentfulIcon`
- `FluidRenderingShopifyIcon`
- `FluidRenderingStoreIcon`
