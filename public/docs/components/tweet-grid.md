# 推文网格 (Tweet Grid)

- 官方文档:https://www.cult-ui.com/docs/components/tweet-grid

## 安装

~~~bash
npx shadcn@latest add @cult-ui/tweet-grid
~~~

## 用法

~~~tsx
import { TweetGrid } from "@/components/ui/tweet-grid"

export function Example() {
  return (
    <TweetGrid>内容</TweetGrid>

}
~~~
