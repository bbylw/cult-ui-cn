# 像素标题(整词) (Pixel Heading Word)

> 整词切换像素字体的标题,悬停可换体或循环。

- 分类:文字与排版
- 本站页面:https://cult-ui.ndjp.net/docs/components/pixel-heading-word
- 官方文档:https://www.cult-ui.com/docs/components/pixel-heading-word
- 源码位置:`src/components/ui/pixel-heading-word.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/pixel-heading-word
~~~

## 用法

~~~tsx
import { PixelHeading } from "@/components/ui/pixel-heading-word"

export function Example() {
  return (
    <PixelHeading>内容</PixelHeading>
  )
}
~~~
