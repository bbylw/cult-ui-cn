# AI 光斑头像 (AI Blob Warp)

> 圆形 AI 助手头像,内部是 Paper Design Warp 着色器,遵循减弱动效设置。

- 分类:AI 组件
- 本站页面:https://cult-ui.ndjp.net/docs/components/ai-blob-warp
- 官方文档:https://www.cult-ui.com/docs/components/ai-blob-warp
- 源码位置:`src/components/ui/ai-blob-warp.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/ai-blob-warp
~~~

## 用法

~~~tsx
import { AiBlobWarpAvatar } from "@/components/ui/ai-blob-warp"

export function Example() {
  return (
    <AiBlobWarpAvatar />
  )
}
~~~
