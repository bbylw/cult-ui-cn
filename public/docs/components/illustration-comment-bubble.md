# 评论气泡插画 (Illustration Comment Bubble)

## 安装

~~~bash
npx shadcn@latest add @cult-ui/illustration-comment-bubble
~~~

## 用法

~~~tsx
import { Code, CommentBubble, CommentBubbleDemo } from "@/components/ui/illustration-comment-bubble"

export function Example() {
  return (
    <Code>
      <CommentBubble />
    </Code>
  )
}
~~~
