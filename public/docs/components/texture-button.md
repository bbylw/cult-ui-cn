# 纹理按钮 (Texture Button)

> 带纹理叠加层的按钮,提供多种预设变体。

- 分类:按钮
- 本站页面:https://cult-ui.ndjp.net/docs/components/texture-button
- 官方文档:https://www.cult-ui.com/docs/components/texture-button
- 源码位置:`src/components/ui/texture-button.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/texture-button
~~~

## 用法

~~~tsx
import { TextureButton } from "@/components/ui/texture-button"

export function Example() {
  return (
    <TextureButton>内容</TextureButton>
  )
}
~~~
