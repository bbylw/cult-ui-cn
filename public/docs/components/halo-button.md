> 带流动渐变边框、磨砂填充与交错文字的主动作按钮,内置加载态。

- 官方文档:https://www.cult-ui.com/docs/components/halo-button

~~~bash
npx shadcn@latest add @cult-ui/halo-button
~~~

## 用法

