# 网格光束 (Grid Beam)

> 网格上流动的光束画布,提供调色板预设、SVG 分隔与 useGridBeam。

- 分类:背景与纹理
- 本站页面:https://cult-ui.ndjp.net/docs/components/grid-beam
- 官方文档:https://www.cult-ui.com/docs/components/grid-beam
- 源码位置:`src/components/ui/grid-beam.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/grid-beam
~~~

## 用法

~~~tsx
import { BeamCanvasRuntimeConfig } from "@/components/ui/grid-beam"

export function Example() {
  return (
    <BeamCanvasRuntimeConfig />
  )
}
~~~
