# 纹理卡片 (Texture Card)

> 带纹理背景与多种样式预设的卡片。

- 官方文档:https://www.cult-ui.com/docs/components/texture-card
- 源码位置:`src/components/ui/texture-card.tsx`

## 安装

~~~bash
npx shadcn@latest add @cult-ui/texture-card
~~~

## 用法

~~~tsx
import { TextureCard, TextureCardContent, TextureCardDescription } from "@/components/ui/texture-card"

export function Example() {
  return (
    <TextureCard>
      <TextureCardContent />
    </TextureCard>
  )
}
~~~
